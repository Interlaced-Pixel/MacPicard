# MusicBrainz-inspired MacPicard identity

The requested redesign takes its palette and restrained geometric character from the [official MusicBrainz identity](https://static.metabrainz.org/MB/header-logo-1f7dc2a.svg) and [MusicBrainz site](https://musicbrainz.org/). Purple `#BA478F` and orange `#EB743B` are the reference colors. MacPicard remains an independent product; neither the MusicBrainz logo nor its wordmark is reproduced.

The native interface uses a split-color MacPicard header, purple action tint, warm neutral surfaces, semantic system text, separators and compact information layouts. Light/dark foreground variants are darker/lighter for legibility. Native materials remain on controls, without the previous blue ambient gradient. System accessibility and window controls remain native.

## Icon provenance

Asset: `Sources/MacPicard/Resources/AppIcon.png` (actual generated source: 1254 × 1254). The native build and standalone packager generate the full `.icns` family from this source. Generated using the built-in imagegen tool in **generation mode**, with no reference image and an opaque background; the original generated output was preserved in the Codex generated-images directory. No official MusicBrainz artwork was copied into the app.

Final prompt:

> Use case: logo-brand. Asset type: production macOS app icon, 1024x1024 square. Create a new MacPicard music metadata app icon inspired by MusicBrainz's clean geometric identity. A large centered faceted hexagonal music-tag emblem: left half magenta-purple #BA478F, right half warm orange #EB743B, with a crisp white musical note cut into the center. Distinct original silhouette, not the MusicBrainz logo or wordmark. Warm near-white squircle tile, generous safe margins, subtle physical depth and soft shadow only, razor-sharp geometric edges, excellent legibility at 32 pixels. No text, no letters, no neon, no blue, no ornamental sparkles, no watermark. Premium restrained native macOS product design.
