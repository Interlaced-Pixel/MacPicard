# MacPicard 1.0.0

MacPicard 1.0.0 is the first public release of the native Swift 6 music-library manager.

## Included

- Managed Music Libraries with copy-on-import, safe removal, recovery, and passive folder monitoring.
- MusicBrainz release and track matching with reviewable assignments and an 85% default confidence threshold.
- Staged metadata and artwork editing with discard, undo/redo, save, and collision-safe organization previews.
- Whole-library matching, scripting, metadata, artwork, save, and organization workflows.
- Native playback, search, filters, collapsed album navigation, keyboard commands, and configurable toolbar controls.
- Built-in audio fingerprint support for MP3, FLAC, M4A/AAC, Ogg Vorbis, Ogg Opus, and WAV without end-user tool installation.
- Recovery journals, atomic persistence, external-change checks, safe API retry/cancellation policy, and migration from older catalog data.

## Distribution

The attached macOS archive is ad-hoc signed for local evaluation. It is not Developer ID signed or notarized. macOS may require an explicit approval in Privacy & Security before opening it.

MacPicard requires macOS 26 or newer.

MacPicard is independent and is not affiliated with MusicBrainz or the Picard project.
